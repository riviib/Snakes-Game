# Snake Game

An interactive browser-based Snake game built using JavaScript, HTML, and CSS. The game includes customizable difficulty through adjustable speed and obstacle settings.

## Features

* Adjustable snake speed for different difficulty levels
* Configurable obstacle settings for added challenge
* Real-time keyboard controls
* Score tracking system
* Collision detection and game over logic

## How to Run

1. Clone the repository
2. Open `index.html` in any web browser

## Technologies Used

* JavaScript
* HTML
* CSS
